# backend-mongo-api

REST API in Go backed by MongoDB, with JWT authentication and auto-generated Swagger documentation.

## Stack

- **Go 1.22** — [Gin](https://github.com/gin-gonic/gin) HTTP framework
- **MongoDB 7** — via the official Go driver
- **JWT** — [golang-jwt/jwt v5](https://github.com/golang-jwt/jwt)
- **Swagger / OpenAPI** — auto-generated by [swaggo/swag](https://github.com/swaggo/swag) on every CI build

## Project structure

```
├── .github/workflows/ci.yml   # Build, generate docs, push image to GHCR
├── internal/
│   ├── handler/               # HTTP handlers (auth + items)
│   ├── middleware/            # JWT auth middleware
│   ├── model/                 # Domain types + request/response DTOs
│   └── repository/            # MongoDB access layer
├── docs/                      # Generated by CI — do not edit manually
├── main.go                    # Bootstrap: Gin router, Swagger annotations
├── Dockerfile
└── docker-compose.yml         # Portainer stack
```

## API endpoints

### Authentication (public)

| Method | Route | Description |
|--------|-------|-------------|
| `POST` | `/api/auth/register` | Create an account, returns a JWT |
| `POST` | `/api/auth/login` | Login, returns a JWT |

### Items (requires `Authorization: Bearer <token>`)

| Method | Route | Description |
|--------|-------|-------------|
| `GET` | `/api/items` | List all items |
| `POST` | `/api/items` | Create an item |
| `GET` | `/api/items/:id` | Get item by ID |
| `PUT` | `/api/items/:id` | Update item |
| `DELETE` | `/api/items/:id` | Delete item |

### Other

| Method | Route | Description |
|--------|-------|-------------|
| `GET` | `/health` | Health check |
| `GET` | `/swagger/index.html` | Swagger UI |

## Swagger

The `docs/` package is **generated automatically** by the CI on every push to `main` via `swag init`, then committed back to the repository. Do not edit files under `docs/` by hand.

To add documentation to a new route, add swag annotations above the handler function:

```go
// MyHandler godoc
// @Summary     Short description
// @Tags        my-tag
// @Accept      json
// @Produce     json
// @Security    BearerAuth
// @Param       body body model.MyRequest true "Payload"
// @Success     200  {object} model.MyResponse
// @Failure     400  {object} model.ErrorResponse
// @Router      /my-route [post]
func (h *MyHandler) MyHandler(c *gin.Context) { ... }
```

Then register the route in `main.go` and push — the CI takes care of the rest.

## Environment variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `MONGODB_URI` | No | `mongodb://localhost:27017` | MongoDB connection string |
| `MONGODB_DB` | No | `mydb` | Database name |
| `JWT_SECRET` | **Yes** | — | Secret used to sign JWT tokens |
| `MONGO_ROOT_USER` | No | `admin` | MongoDB root username |
| `MONGO_ROOT_PASSWORD` | **Yes** | — | MongoDB root password |
| `API_IMAGE` | No | `ghcr.io/ronanlambare/backend-mongo-api:latest` | Docker image reference |
| `API_PORT` | No | `8080` | Host port |

Copy `.env.example` to `.env` and fill in the required values.

## CI / CD

On every push to `main`, the GitHub Actions workflow:

1. Installs Go and `swag`
2. Runs `swag init` + `go mod tidy` — generates `docs/` and `go.sum`
3. Commits the generated files back to `main` (`[skip ci]`)
4. Builds the Docker image (multi-stage, distroless alpine)
5. Pushes to `ghcr.io/ronanlambare/backend-mongo-api` with tags `latest` and `sha-<commit>`

## Deployment (Portainer)

1. In Portainer, create a new **Stack**
2. Set the source to **Repository** and point it to this repo
3. Set the compose file path to `docker-compose.yml`
4. Add the required environment variables (`MONGO_ROOT_PASSWORD`, `JWT_SECRET`, optionally `API_IMAGE`)
5. Deploy — Portainer will pull the image from GHCR and start both containers
